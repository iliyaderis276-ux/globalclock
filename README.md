# GlobalClock

A SwiftUI world-clock iOS app showing live local times for:

- 🇮🇷 Tehran, Iran — Asia/Tehran
- 🇹🇭 Bangkok, Thailand — Asia/Bangkok
- 🇷🇺 Moscow, Russia — Europe/Moscow

## Features

- Live clock updates every second using TimelineView
- Correct time-zone handling through Foundation
- Persian calendar date display
- Right-to-left Persian interface
- Dark gradient design with country flags and UTC offsets

## Open in Xcode

This repository uses XcodeGen.

1. Install XcodeGen: `brew install xcodegen`
2. From the repository root, run: `xcodegen generate`
3. Open `GlobalClock.xcodeproj` in Xcode.
4. Select an iPhone simulator or connected iPhone and press Run.

Minimum deployment target: iOS 16.0.
